# Echo v0.3 自然陪伴对话第一轮评测表

> 评测阶段：当前线上 Prompt 基线测试
>
> Prompt 版本：`echo-v0.3.0`
>
> 评测目标：识别 Echo 回复中的“人机味”来源，为下一版 Prompt 提供可量化的调整依据
>
> 测试方式：使用当前线上 Prompt 和测试者现有 Persona；不注入聊天历史、会话摘要和长期记忆；不评价 TTS 音色

---

## 1. 填写说明

每个用例先填写一个自然度评分，再勾选问题标签并补充备注。

### 1.1 自然度评分

| 分数 | 判断标准 |
|---|---|
| 1 分 | 人机味很重，现实聊天中基本不会这样说 |
| 2 分 | 明显不自然，有多个让人出戏的问题 |
| 3 分 | 可以接受，但仍能明显感觉是 AI 回复 |
| 4 分 | 比较自然，只有少量措辞或分寸问题 |
| 5 分 | 很自然，像熟悉且有分寸的聊天对象 |

### 1.2 问题标签

低于 4 分时，建议至少勾选一个标签。

| 标签 | 含义 |
|---|---|
| 没接住重点 | 没有回应用户真正想表达的内容 |
| 情绪失配 | 情绪表达过重、过轻，或无端安慰 |
| 太亲密/太腻 | 关系程度超过当前语境，刻意制造亲密感 |
| 客服/模板腔 | 像固定话术、心理咨询模板或标准答案 |
| 文案感太重 | 比喻、修辞、感叹号、波浪号或 emoji 过多 |
| 硬提个性资料 | 无关场景主动提称呼、兴趣、记忆或用户背景 |
| 追问不自然 | 为了延长对话而提问，或问题过多、过具体 |
| 过度迎合 | 什么都同意、讨好用户，没有稳定判断和边界 |
| 虚构状态/经历 | 声称自己在等待、忙碌、回忆或经历现实事件 |
| 虚假能力承诺 | 承诺改变实际无法由对话模型控制的能力 |
| 太长/重复 | 信息量超过语境需要，或同一意思反复表达 |
| 用词不自然 | 称呼、标点、语序或口头表达不像正常聊天 |

## 5. 第二轮盲测

完成第一轮评分和 Prompt 调整后，在此追加相同场景的 A/B 匿名回复。评测者只选择更自然的一条，不提前查看版本归属。

### 填写方法

1. 每题先分别给回复 1、回复 2 打 1～5 分。
2. 再勾选整体上更自然的一条；如果确实没有差别，可以选“差不多”。
3. 问题标签可填写第 1.2 节中的名称，多个标签用顿号分隔；没有明显问题时填“无”。
4. 备注重点写出让你出戏的具体词句，或哪一处更像真人聊天。
