# Echo 小程序基础体验版发布清单

> 目标：仅邀请指定体验成员进行基础业务验证，不做公开传播或正式分阶段发布。

## 1. 已在代码中完成的 P0

- [x] 体验版、正式版关闭客户端提示词管理入口，不携带管理 Token。
- [x] 后端管理调试 API 默认关闭；弱 Token 无法误开启。
- [x] Bearer Token 为默认鉴权方式，旧 `user_id` 鉴权默认关闭。
- [x] 登录失败不再伪装成匿名登录，页面提供重新登录入口。
- [x] “清除上下文”会删除当前登录用户的服务端聊天记录和摘要，不再只清屏幕。
- [x] 聊天内容长度限制为 2000 字符。
- [x] 登录、聊天、语音增加单用户/IP 和全局请求配额。
- [x] 语音上传限制为 10 MiB，并采用限长分块读取。
- [x] PostgreSQL 和 FastAPI Docker 端口仅绑定 `127.0.0.1`。
- [x] 增加 `/health/ready`、`/version` 和最小 HTTP 耗时日志。
- [x] 系统提示词之后固定注入不可编辑的基础安全规则。

## 2. 发布前人工门禁

以下项目需要部署服务器或微信管理后台权限，不能只靠仓库代码完成。

### 2.1 固化发布版本

- [ ] 所有计划发布的修改已 review 并提交。
- [ ] 创建版本标签，例如 `v0.2.0-gray.1`。
- [ ] `Echo-backend/.env` 设置实际版本：

```dotenv
APP_VERSION=0.2.0-gray.1
BUILD_REVISION=<git commit sha>
ENABLE_API_DOCS=false
ENABLE_ADMIN_DEBUG_API=false
ADMIN_DEBUG_TOKEN=
ENABLE_LEGACY_USER_ID_AUTH=false
```

### 2.2 服务器部署与验证

```bash
docker compose config --quiet
docker compose up -d --build
docker compose ps
docker compose logs --tail=200 echo-backend
```

- [ ] `GET https://api.echoaiforever.cn/` 返回 200。
- [ ] `GET https://api.echoaiforever.cn/health/ready` 返回 200。
- [ ] `GET https://api.echoaiforever.cn/version` 与发布标签、commit 一致。
- [ ] `/admin/debug/prompt` 和 `/admin/debug/chat/clear` 返回 404。
- [ ] `/docs`、`/redoc` 和 `/openapi.json` 均返回 404。
- [ ] `/memory/backfill-embeddings` 返回 404。
- [ ] 未携带 Bearer Token 访问 `/memory/list` 返回 401。
- [ ] 公网无法直接连接 8000 和 5432 端口。
- [ ] Nginx 已应用 `deploy/nginx/echo-api.conf.example` 中的请求体限制和反向代理安全设置。

### 2.3 成本与备份

- [ ] LLM、Embedding、ASR、TTS 服务商控制台已设置预算上限或余额告警。
- [ ] `echo-postgres-backup` 正常运行并生成当天备份。
- [ ] 选择一份备份完成恢复演练，记录时间和结果。
- [ ] 明确回滚 commit/镜像；数据库变更如不向后兼容，准备对应恢复步骤。

### 2.4 微信平台配置

- [ ] `request` 合法域名包含 `https://api.echoaiforever.cn`。
- [ ] `uploadFile` 合法域名包含 `https://api.echoaiforever.cn`。
- [ ] `downloadFile` 合法域名包含 `https://api.echoaiforever.cn`。
- [ ] 《小程序用户隐私保护指引》说明微信登录标识、聊天文本、长期记忆、录音、第三方 AI/语音服务、保存期限和删除方式。
- [ ] 真机首次录音能正确触发微信隐私授权和 `scope.record` 授权。
- [ ] 体验成员仅添加本轮指定人员，体验版二维码不公开传播。

## 3. 真机端到端验收

至少使用两个不同微信账号执行：

- [ ] 登录成功并保存 Bearer Token。
- [ ] 文字聊天成功，连续追问能承接上下文。
- [ ] 用户 A 和用户 B 的聊天、长期记忆完全隔离。
- [ ] “以后叫我小安”能生成记忆；删除后不再召回。
- [ ] “清除上下文”能删除本人聊天记录但不误删长期记忆或其他用户数据。
- [ ] 语音录制、上传、ASR、文字回复成功。
- [ ] TTS 失败时仍保留文字回复。
- [ ] 断网、Token 失效、429、413、第三方超时都有用户可理解的提示。
- [ ] 服务重启后聊天和记忆仍可读取。
- [ ] 日志中没有 Token、openid、微信 code、聊天正文和语音识别正文。

## 4. Go / No-Go

只有第 2、3 节全部完成，才上传并设置基础体验版。任一情况出现时停止新增体验成员：

- 越权读取或修改其他用户数据；
- 管理接口仍可公网访问；
- 登录、聊天主链路持续失败；
- 数据库没有有效备份或无法恢复；
- 模型成本失控；
- 严重危险内容或隐私泄露。
