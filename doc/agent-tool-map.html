思路：把 35 个工具拆成「常驻核心」和「条件域包」。域包只在真的有用时才进 prompt：桌面在线才给桌面包，手机在线才给手机包，关系可推进才给关系包。

相对现状节省–
为什么不是一刀切删工具：能力要保留，只是不该每轮都出现在 prompt 里。设备离线时模型本来也调不动，删掉注入只是让它别再纠结要不要调。
