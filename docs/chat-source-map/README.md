# 上下文来源与规则地图

使用浏览器打开 `index.html`。全部样式、语义图表、Dagre 布局引擎与源码定位索引均在单个 HTML 中，无需网络或服务器。

五张图分别展示产品与人格、用户偏好与关系、记忆与摘要、运行时组装、规则定义与校验。点击节点查看文件、定位行、函数与测试。页面下方有可搜索的规则对照表和完整定位清单。

- `diagrams.json`：不含布局坐标的结构规格，每图不超过 12 节点。
- `source-index.json`：构建时验证存在的源码定位与规则映射。
- `build_page.py`：文案、规格、证据与生成程序；运行后重新获取定位行。
- `template.html`：离线页面模板。
- `verify_page.cjs`：离线脚本检查，不代替浏览器视觉验收。

重新构建：`python build_page.py`。检查：`node verify_page.cjs`。构建复用相邻 `chat-flow-page/vendor` 引擎；生成后的 HTML 可独立复制。

本页没有读取 .env 实际内容、部署密钥或真实用户数据库。源码定位是工作区快照，测试只标注位置，没有运行后端测试或模型评测；不能把测试存在视为已经通过。当前没有可连接浏览器，尚未完成浏览器视觉验收。
