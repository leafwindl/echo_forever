05 / PROMPTS AND CODE GATES
写进 Prompt，与代码确实校验，有什么区别？
Prompt 表达期望，程序落实可以确定判断的条件。一次上下文组装不会自动获得通用事实核验能力。
检查对象当前定义／执行处当前能保证什么，边界在哪
人设与说话方式人格对象、规则 MD、Renderer；
部分表达在 dialogue_style 中检测。		有限模式检测与兜底，可能误判、漏判；不能保证模型始终符合整个人格。
偏好字段请求 Schema + build_user_preferences；
Renderer 处理边界字符与长度。		类型、枚举、长度等有代码约束；自然语言内容仍须当作数据处理。
工具是否允许执行Agent 本步白名单与整轮预算；
ToolExecutor 参数、模式、次数、去重与超时。		通过门禁后才调用 handler；资源归属和业务有效性还由具体用例检查。同轮去重不等于跨轮幂等。
动作是否成功工具返回状态、call_id 配对；
部分能力另核对真实交付凭据。		不能把调用申请说成成功。表情有专门的成功依据检查，不是所有事实都有同样的通用检测器。
记忆与摘要记忆操作有类型／置信度等检查；
摘要更新主要去空白、检查非空。		摘要的来源格式与事实归属主要靠提示。来源编号可用，不等于事实已被证实。
最终回复格式Agent delivery rule；
validate_agent_delivery_segments + 保存前检查。		可检查空段、重复、段数、部分内部字段等；不是任意事实核验或所有提示泄漏检测。
相关文件和获取链都在上方来源卡片中。架构规范还由 scripts/check_architecture.py 检查部分边界；这些开发期检查不是每次模型请求时自动进行的业务校验。


06 / WHAT OCCUPIES THE CONTEXT
哪些每次都带？长度在哪里限制？
当前固定提示占比不小。外置成 MD 让内容更易维护；只有删减、去重或确实不注入，才会减少相应输入材料。
固定文字 · 项目字符权重估算
5,259估算 token
默认文字聊天、默认启用偏好、初识关系的隔离组装场景。不是 tokenizer 精确计数，也不是 API usage 或账单。
未计：历史、记忆、摘要正文、时间 JSON、当前输入、工具 schema、工具结果与重试。固定值来自项目的离线审计快照；部署覆盖会改变结果。
当前的局部限制
  • 用户偏好：默认 400。
    persona_prompt_max_tokens 限制的是用户偏好文本，不是整个 Echo 人格。
  • 长期记忆：默认 800。
    memory_prompt_max_tokens 限制格式化正文；外围标签另占长度。
  • 会话摘要：默认 800。
    summary_prompt_max_tokens 限制注入正文；摘要生成另有输出上限，二者不同。
  • 近期历史：最多 20 条数据库消息。
    这是数量限制。长消息、时间标记与附件语义会使总长度浮动。
  • 整份输入仍需要统一预算。
    当前这条组装链没有对所有 messages + tools 做完整的全局输入裁剪。模型的 max_tokens 是输出上限，不能当输入总预算。
上述数值是 Settings 源码默认值，可被环境覆盖。_truncate_to_token_budget() 使用项目字符权重估算，不同于供应商 tokenizer。


07 / IMPLEMENTATION BOUNDARIES
阅读这份图时，需要区分的几种情况
本页主要展示普通文字聊天。其他模式共用一部分机制，但不会照搬完全相同的上下文。
语音通话与私人数据权限
通话使用 call-dialogue 与精简时间、历史，默认不带记忆／摘要；明确回忆时可扩展。speaker_role=unknown/known 在此上下文构建中都按无账号私人数据权限处理，不带私人偏好、历史、记忆和摘要，关系 guidance 回退。
memory_enabled 的范围
当前该参数关闭时，会一起跳过长期记忆、摘要、历史和私人对话时间；它不会自动关闭固定人设、产品定位、规则，也不会自动停止读取显式偏好与关系状态。演示区“召回记忆”开关只控制一块示意材料。
主动消息与每日来信
主动触发另有 planner／writer、安全事实与时间元数据处理，本轮触发不是用户发言。来信由 letters 的上下文用例准备昨日证据及专注材料，并采用结构化输出；不是普通聊天多加一句任务提示。
当前实现与下一步设计
共享 renderer 与四份规则 MD 已在用。人格、Agent 合同尚未全部外置，也没有完整六类资产注册与 profiles 选择引擎。后续实现应遵循项目规范，接入真实消费者后再增加资产。
维护入口：doc/Echo 后端架构与代码规范.md。本页源码定位在生成时核对；它是架构说明快照，不会在浏览器里实时跟踪后端执行。源码变动后运行同目录 build_page.py 可刷新行号和片段。
