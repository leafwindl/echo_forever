一条消息，

从点击发送，到校验、排队、模型思考与工具执行，再回到聊天气泡。沿着四张图，看懂项目当前的文字聊天流程。

WHAT TO REMEMBER / 核心要点

    EXPLORE / 点击节点查看解释

    “正确、高效”怎么判断？

    已有保护机制，是检查的起点。

    01 / 发送不重复

    重点验证：服务端已保存但确认包丢失后，用原编号重试，应只有一条用户消息。

    02 / 动作有真实依据

    重点验证：非法参数、重复调用、超时均不会被误报成功；有副作用的动作还要验证跨轮幂等。

    03 / 等待可分段解释

    分别观察排队、上下文构建、模型、工具与保存后处理耗时，再决定优化哪里。

    布局与离线说明

    节点、边、分组与布局意图来自语义 JSON。页面内置 Dagre 1.1.5 自动布局引擎，渲染器根据引擎输出生成 SVG；未为具体图表手工指定坐标。导出的 JSON 不含坐标、尺寸或路径。渲染器采用折线路由，分组以标签与节点说明表达，不强制聚类边框。所有脚本与样式内嵌，禁止页面发起网络连接。
