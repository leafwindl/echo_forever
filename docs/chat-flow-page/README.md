# Echo 聊天流程讲解页

双击 `index.html`，使用浏览器打开即可。单个 HTML 内置样式、语义数据和 Dagre 布局引擎，无需服务器和网络。

- 四个章节可以切换；点击流程节点查看解释，节点也支持键盘操作。
- “导出图表 JSON”下载不含坐标的结构规格；同目录的 `diagrams.json` 是相同内容。
- `build_page.py` 保存文案、图表语义与结构校验；`template.html` 是离线页面模板。
- 布局坐标由内嵌 Dagre 自动计算，图表规格没有手工坐标。渲染器根据自动布局生成折线 SVG。
- 修改后执行 `python build_page.py` 重新生成，再执行 `node verify_page.cjs` 检查布局和交互脚本。
- `vendor` 内的引擎与许可证仅用于重新构建；把 `index.html` 单独复制出去也能打开。

说明基于制作时当前工作区代码，仅覆盖 APP 文字和表情聊天。不是运行压测结果，也不是完整正确性或安全审计。

页面结构与脚本的离线检查覆盖四张图、全部节点说明、章节切换、键盘导航与 JSON 导出。当前工具环境无可连接的浏览器，尚未完成浏览器视觉验收。
