    “正确、高效”怎么判断？

    已有保护机制，是检查的起点。

    01 / 发送不重复

    重点验证：服务端已保存但确认包丢失后，用原编号重试，应只有一条用户消息。

    02 / 动作有真实依据

    重点验证：非法参数、重复调用、超时均不会被误报成功；有副作用的动作还要验证跨轮幂等。

    03 / 等待可分段解释

    分别观察排队、上下文构建、模型、工具与保存后处理耗时，再决定优化哪里。
