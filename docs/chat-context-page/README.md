# Echo 上下文与 Prompt 可视化讲解

用浏览器打开 `index.html` 即可，单个 HTML 包含全部布局脚本、样式和数据，无需服务器与网络。

四部分：信息来源、组装顺序、约束分工、选择与预算。点击节点查看来源和约束说明；支持键盘选择节点、切换章节与下载语义 JSON。

`diagrams.json` 为不含坐标的图表规格。布局由内嵌 Dagre 自动计算，每图不超过 12 个节点。

页面依据当前工作区代码整理，配置数字是默认值，未读取部署环境覆盖值；没有运行后端或完整安全审计。

重新构建：`python build_page.py`。构建时复用相邻 `chat-flow-page/vendor` 内已有的引擎与许可证；生成的 HTML 可单独复制使用。

校验：`node verify_page.cjs`，覆盖图表渲染脚本、节点说明、章节切换、键盘导航和导出内容。当前无可连接浏览器，未完成实际浏览器视觉验收。
