上下文不是完整聊天记录的复制品。它由规则、相关背景、近期原文和当前消息共同组成；沿着四张图，看懂信息怎样进入模型，又怎样受到约束。

每次请求，重新准备一份材料。

    先记住三个区别

    理解上下文，最容易混淆的是这些。

    01 / 携带 ≠ 必须提起

    材料里有称呼、记忆或旧话题，不表示回复必须提它们。普通问候不应因为带了工作记忆，就突然追问工作。

    02 / 低权限标记 ≠ 独立隔离

    当前背景仍通过 system 消息承载。“只作数据”的提示有帮助，但不能当成完整的权限隔离或防注入证明。

    03 / 局部预算 ≠ 总请求上限

    偏好、记忆和摘要各自截断后，还会加入固定规则、历史、工具定义与结果；整份上下文仍需关注总量。
