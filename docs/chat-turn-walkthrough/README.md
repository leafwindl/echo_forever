# 一轮真实聊天的离线拆解课

页面只跟随一个已发生的文字聊天轮次。默认一次解释一步，支持查看请求形状、逐条装配 messages、定位项目源码、入口校验模拟及工具结果回填支线。所有依赖内置，不需要服务器、网络或登录。

生成器读取本地私有快照 `data/chat-turn-walkthrough/case.json`，输出 `data/chat-turn-walkthrough/index.html`。该目录由根 `.gitignore` 忽略；聊天原文与个性化页面不进入 Git。快照通过对已授权账号的服务器数据库只读查询取得，本生成器不连接数据库、不调用模型、不读取运行环境密钥。

```powershell
python docs/chat-turn-walkthrough/build_page.py
node docs/chat-turn-walkthrough/verify_page.cjs
```

双击生成的 HTML 即可学习。起始步骤也可以用 `#step-6` 等本地 URL 片段指定。

证据边界：

- 聊天原文、保存气泡、轮次时间、主 Agent step_count 及工具调用记录来自只读数据库快照。
- 未留存的原始模型请求、动态偏好、关系、摘要、记忆召回、原始模型响应和门禁轨迹不会被伪造。
- 固定提示词从当前源码通过隔离的纯渲染逻辑取得；产品配置取源码默认值，不声称是当时部署值。
- 消息列表和事件结构是带占位及匿名关联编号的教学复原，工具 Schema 仅展示一个当前真实定义，不可作为完整生产请求。
- 先前 9 条原文是历史候选；页面无法证明当时摘要边界与最终历史筛选结果。
- 工具支线和校验实验均是本地模拟，不能用来测量模型效果或线上校验结果。
- token 是项目已有字符权重估算，不是 tokenizer 或账单；不包含全部动态材料、工具 Schema、协议与辅助调用。

流程语义在构建数据的 `graph` 中定义；内置的本地 Dagre 根据节点与边自动布局 SVG，无手工节点位置。Dagre 与许可来自 `docs/chat-flow-page/vendor/`，许可随输出内置。文件路径、源码摘录与规范化源码 SHA-256 同时打包以便离线查阅和防止说明漂移。
