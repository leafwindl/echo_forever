# Echo 电脑主动陪伴计划

更新日期：2026-11-02

## 1. 目标

Echo 不再只等用户下指令，而是能根据聊天、情绪和时间，主动做一点事：

- 打开网易云，搜索并播放指定歌曲
- 打开记事本，写下一段话
- 让 DSH 执行任务，读取最终结果并简单总结
- 做完后在聊天里自然说明，不静默操作

## 2. 当前状态

已有：

- Windows 电脑节点、桌面客户端
- 打开网易云/记事本/计算器
- 网易云播放/暂停/下一首/上一首
- 单次摄像头抓拍和屏幕截图
- 客户端状态、日志、总是允许开关
- 后端配对、在线状态、动作审计

还没有：

- 网易云搜歌和播放指定歌曲
- 记事本自动打字
- DSH 任务桥
- 主动动作决策
- 按动作类别设置频率和开关

## 3. 总体结构

```text
聊天 / 主动触发
      ↓
Echo 后端：情绪、上下文、动作决策、频率控制
      ↓
电脑节点：打开应用、音乐、记事本、DSH
      ↓
客户端：状态、动作记录、DSH 结果、日志、停止
```

原则：

- 动作是内部能力，不做成用户指令
- 模型决定做什么，代码决定能不能做
- DSH 开独立任务，不注入当前会话
- 动作用户可见，失败要如实说明

## 4. 阶段一：动作基础

### 网易云搜歌/播放

- 支持“放周杰伦的晴天”这类指定歌曲
- 也支持按情绪让 Echo 自己选歌
- 打开网易云 → 搜索 → 点第一首 → 播放
- 尽可能验证实际播放结果

### 记事本打字

- 打开新记事本
- 用剪贴板写入中文
- 不覆盖已有文档
- 默认不自动保存

### 验收

- 指定歌名能搜索并播放
- 中文能正确输入
- 搜不到/播放失败不能假装成功
- 客户端能看到动作日志

## 5. 阶段二：DSH 任务桥

- Echo 发任务给 DSH
- 不限制工作区，DSH 完全权限
- 开独立任务，不碰当前 DSH 会话
- 任务完成后只把最终摘要带回聊天
- 客户端显示任务状态、耗时、详细日志和停止按钮
- 长任务异步执行，完成后 Echo 再发一条总结

验收：

- “让 DSH 检查这个项目并跑测试”
- 客户端能看到开始/运行/结束
- Echo 收到结果并简短说明
- 失败、超时能说清楚

## 6. 阶段三：主动动作

### 触发

- 聊天里的难过、累、焦虑、失眠
- 主动聊天周期
- 用户提过的项目或任务
- 深夜、周末、关系熟悉程度

### 决策结果

- 不动作
- 只发消息
- 发消息 + 放歌
- 发消息 + 记事本写字
- 发消息 + 启动 DSH 任务

### 代码约束

- 每类动作有冷却和每日上限
- 用户没回应就暂停主动动作
- 安静时段不动作
- 不重复上一首/上一段内容
- 音乐、记事本、DSH 可以分别开关
- 全局暂停主动动作

### 默认建议

| 项目 | 默认 |
| --- | --- |
| 音乐主动动作 | 每天最多 2–3 次，同类间隔至少 2 小时 |
| 记事本主动动作 | 每天最多 1–2 次 |
| DSH 主动任务 | 只在对话已有明确任务意图时启动 |
| 动作前提示 | 先说一句，再执行 |
| 记事本保存 | 默认不保存，只开新文档 |

## 7. 客户端升级

- 状态页
- 动作记录
- DSH 任务页
- 音乐/记事本/DSH 分类开关
- 频率设置
- 停止当前动作
- 完整日志

## 8. 安全边界

- 普通电脑动作默认总是允许
- DSH 完全权限，不限制工作区
- 客户端保留停止按钮和完整日志
- 每次动作写入审计
- 不保存摄像头/屏幕图片
- DSH 只在独立任务中运行

## 9. 待拍板

1. 主动动作频率是否采用上面的默认值？
2. 动作前是否必须先发一句提示？
3. DSH 主动任务只做“对话里已有明确任务”，还是允许 Echo 自己找任务？
4. 记事本是否允许自动保存文件？
5. 网易云是否同时支持精确歌名和按情绪选歌？

## 10. 推荐顺序

1. 网易云搜歌/播放 + 记事本打字 + 动作日志
2. DSH 任务桥和客户端 DSH 面板
3. 主动动作决策、频率控制和分类开关
4. 完整测试和上线

先把动作做可靠，再让 Echo 主动使用它们。
